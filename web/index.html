What it does

Out of your way, fast

⚡

Live, no refreshing

Mail streams in over a WebSocket and lands in the list instantly, with the code shown right in the row.

🎯

Codes pulled out

The verification code or login link is detected for you. Order numbers, prices and dates are ignored, backed by 80+ tests.

🤖

Scripts and agents

--code, --json and real exit codes for CI, plus an MCP server so AI agents can grab codes on their own.

Three ways in

People, scripts, and agents

Interactive
$ mailbust
$ mailbust testing
$ mailbust testing -t 1h
Scripting and CI
$ mailbust --new --json
$ mailbust box --code
$ mailbust box --list --json
MCP for agents
$ mailbust mcp
