Why it's nice

Fast, honest, and out of your way

⚡

Instantly live

Mail streams in over WebSocket - no refreshing. The code appears right in the list, so you rarely open an email.

🎯

Codes extracted

It finds the real verification code or magic link and ignores order numbers, prices, dates and years. Backed by 84 tests.

🤖

Scripts & agents

--code, --json and real exit codes for CI - plus an MCP server so AI agents can grab codes themselves.
